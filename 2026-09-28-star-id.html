Caelus Studio 推出统一账号「Star ID」：一个邮箱，通行全站

Caelus Studio 统一账号「Star ID」正式上线。用一个邮箱注册，即可通行主站与周边商店，新闻中心与 VBA 工具站将陆续接入。

各位关注 Caelus Studio 的朋友：这一年来我们陆续上线了主站、周边商店、新闻中心与 VBA 工具站，站点越来越多，账号却一直是各管各的——在商店填过的资料，换个站点又要填一遍；登录状态也不能跨站点延续。Star ID 就是为解决这个问题而做的。

什么是 Star ID

Star ID 是 Caelus Studio 的统一账号。注册成功后你会拿到一个形如 CS-XXXXXXXX 的编号，它与你的邮箱绑定，用来代表你在 Caelus Studio 的身份。这个编号一经生成就不再变化，修改昵称或资料都不会影响它。

现在能做什么

一处登录，全站通行：在主站或商店登录后，其他已接入站点自动保持登录状态
账号中心：查看与修改昵称、联系信息，查看登录与操作记录
安全提醒：登录、修改资料、修改密码都会发一封提醒邮件，含时间、IP、大致位置与所用系统
自助注销：可在账号中心申请注销，确认后永久删除

怎么开通

打开账号中心，输入邮箱，收取六位验证码，设置一个密码即可开通。验证码十分钟内有效，同一邮箱每隔六十秒才能再发一次。全程不需要手机号，也不收取任何费用。

账号中心：https://www.caelus.top/account/

关于安全

账号安全最容易被轻视，也最不该被轻视。Star ID 的做法是：密码不明文保存；每次登录都发提醒邮件；忘记密码时需要回答三个与你本人使用习惯相关的问题，经人工审核通过后才会发放临时密码。如果收到的提醒邮件并非你本人操作，可据此及时处理。

写在最后

Star ID 免费开通，也不改变现有的领取与购买方式——QQ 群成员领取钥匙扣的流程照旧。接下来我们会把新闻中心与 VBA 工具站一并接入，届时一个账号即可走遍 Caelus Studio。
